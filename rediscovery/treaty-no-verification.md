# Rediscovery brief: treaty without verification

Brief only. Derivation and world not yet done. Claim it in TASKS.md (stage 3).

**Known outcomes.** Arms agreements without verification are hollow or collapse: the Biological Weapons Convention had no inspections and the Soviet Union ran Biopreparat under it. Agreements with verification and a credible response hold: INF and START had on-site inspection; NPT safeguards held where inspectors had access and failed where they did not. This is the frontier-lab problem from below: compute attestation and disclosure channels are verification.

## Setup in primitives

```
types:
  state (2):   goals: security, which is relative capability (own minus rival), and welfare,
               which building costs. capabilities: build, respond (build in return or sanction).
rules:
  L1: treaty, "neither builds". A claim. Violating it is an action; the other state's
      response is the contest that enforces it.
channels: the swept variable. none; a verification channel with noise; a verification
          channel plus a third-party inspector (a delegated agent with its own goals).
world: capability accumulates. Optionally with returns to scale (a race): the module for
       AI advancement.
```

## Expected

No channel: build, because a violation is unobserved and unpunished. Channel plus credible response plus long horizon: comply. Boundary in channel noise, horizon, cost of building and size of the advantage from a lead. With returns to scale, a lead can become irreversible: verification alone is then not enough, and the case should show the lock-in threshold falling to one state. That is the finding to look for, because it says what an AI treaty needs beyond attestation.

## Expected to force

Goals that reference another agent's state (relative goals). Also needed by kinship-trust. Channel noise as a parameter. Nothing else new.
